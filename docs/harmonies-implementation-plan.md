# 自然和弦（Harmonies）实施计划

分支：`codex/add-harmonies`。从当前 `codex/splendor-longterm-memory` 分支建立。

## 范围与规则基线

- 1–4 人基础游戏、A 面河流/B 面岛屿、32 张动物牌、可选 10 张自然之灵。
- 120 枚地形，23 格个人六角棋盘；严格堆叠、旋转匹配（不镜像）、动物锁定、部分完成计分。
- 单人市场弃置与刷新、同等回合终局、动物数量破同分。
- 无扩展；使用原创 SVG/CSS，动物牌以稳定编号表示，不附出版商美术。

规则来源：[Libellud 英文规则](https://cdn.svc.asmodee.net/production-libellud/uploads/2024/12/HARMONIES_Rules_EN.pdf)。
卡牌机械数据参考 [harmonies-bot](https://github.com/miles2542/harmonies-bot)，固定提交
`a5ffa20f4d6206632eec2c83e93c39cff79283c8` 的 `docs/cards_database.json`（Apache-2.0）。
仅转换卡牌图案和数值，独立编写引擎；来源与授权随仓库保存。官方规则优先于参考项目文字说明。

## 实施步骤

1. **规则与数据**：冻结规则/状态版本，转换牌库和轴坐标，记录范围。
2. **后端引擎**：实现 GamePlugin；复用 ActionSpace、事件、哈希、拓扑和排名。
   - 每回合一次拿地形、一次可选拿牌，逐枚放置，可穿插安置动物，显式结束回合。
   - 决策计数与完整回合计数分离；牌库/袋子顺序不进入玩家观察。
   - 保证非法动作不修改状态，动作标识随决策更新，状态可 JSON 持久化并确定性回放。
3. **接入**：注册游戏、Harness profile、CLI/Store/Web API 通用流程。
4. **前端**：中英双语入口、设置、六角地形层、动物牌图案/进度、合法格点选、市场和计分。
5. **验证**：规则场景、守恒、全牌旋转、单/多人随机完局、重放、Web 人类操作；运行 Python 回归、TS、lint 和 Web 构建测试；浏览器检查桌面/窄屏。

## 已实现接口

- `take_tokens {group}`：拿取一组三枚地形。
- `place_token {color, cell}`：逐枚放置；格子编号在协议中从 0 开始，在界面中从 1 开始。
- `take_animal {card_id}`：本回合至多一次，未完成牌至多四张。
- `choose_spirit {card_id}`：首回合开始选择自己的自然之灵。
- `place_animal {card_id, cell}`：服务器验证六种旋转中至少一种匹配；同一目标的等价图案只枚举一次。
- `end_turn {discard_card?}`：必选地形全部放置后才可执行；可选字段只供单人未拿牌的回合换牌。

`turn_count` 记录协议决策步数，`completed_turns` 记录完成的玩家回合数，`round` 记录轮次。
观察内含规则速查、完整可见牌面、地形与分项计分，牌袋/牌库只公开数量。
自然之灵候选只对持有者可见。单人结果附太阳等级。

## 边界与实现决策

- 状态为 `playable_beta`：动物牌以稳定编号显示，42 张机械数据来自上述固定版本的社区转录，未声称得到出版商认证。
- 引擎独立按官方规则实现：建筑最高两层，动物栖息地要求完整建筑；参考项目允许单红匹配的逻辑未沿用。
- 河流计算连通水域中任意两点的最大最短路径，包含两端；环路不能绕远增加分数。
- 自然之灵采用勘误后的建筑群 6 分。太阳等级含地图与自然之灵类型修正。
- 不含 Pulse 等扩展、出版商美术或外部模型实际付费对战；模型入口复用统一插件/Harness 协议。

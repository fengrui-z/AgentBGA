### 人类策略对照

用户观察：在首个保护项目通常仍处于对局前中期时，有经验的人类玩家往往更偏好“立即获得并在每次休息时再次获得”的奖励，例如免费 2 格围栏或精选一张牌。这类奖励能够在后续多个休息阶段重复产生价值，通常比一次性的 12 金币或新增事务员具有更高的长期收益。

这不是无条件的最优性断言：若玩家急需现金完成关键动物组合、事务员能立即转换为高价值协会行动，或预计剩余休息次数很少，一次性奖励仍可能合理。但本局两位 Agent 都在第一次支持保护项目时选择一次性奖励，值得作为“即时收益偏好、长期复利价值估计不足”的候选能力差距追踪。

### 后续评测建议

- 统计首次保护项目时选择“可重复收入奖励”与“一次性奖励”的比例。
- 在选择发生时记录预计剩余休息次数、现金、空围栏、手牌质量、可用事务员及下一回合可执行动作，用于判断选择是合理战术还是短视。
- 对比不同模型与 Harness 是否会主动估算奖励的累计价值，而不仅比较立即到账的名义数值。
- 检查给 Agent 的合法动作说明是否清楚标出 `immediate_and_income` 与 `immediate`，以及可重复奖励将在每次休息时再次触发。

# P1 official action-domain status

Updated: 2026-08-25

P1 supplies concrete, serializable legal choices beneath the generic Action
card session.  Every action is checked by the server before state mutation.

## Delivered

- Cards I/II: draw tables, deck/display sources, Reputation slots, Snap,
  mandatory discard, physical display gaps, deterministic discard recycling,
  Multiplier executions, Break movement, and after-finishing refill.
- Build I/II: Map 0 terrain, border/adjacency, Build-II spaces, fixed polyhex
  rotations, different-building budget, cost, kiosk distance, unique special
  enclosures, placement bonuses, map completion, card reward, and correctly
  deferred Clever resolution.
- Animals I/II: card-first then enclosure selection, hand/display sources,
  strength-five Reputation, requirements, partner-zoo discount, standard and
  special enclosure capacity, rock/water adjacency, physical card instances,
  immediate semantic effects, and deferred display refill.
- Association I/II: increasing worker cost for repeated tasks, different-task
  budget, partner zoos, universities, asset rewards, conservation-project
  bridge, donation, and persistent association stock ownership.
- Sponsors I/II: single/multiple card budget, hand/display sources,
  prerequisites, physical instances, Break/money alternative, and deferred
  display refill.
- Unified routing intersects Action-card start envelopes with actual domain
  choices, preventing an empty hand, missing enclosure, insufficient workers,
  or unavailable card source from opening an unfinishable action session.

## Historical gates closed by P2–P8

- P3 records and validates unique Sponsor-building footprints and placement
  effects; none execute as text-only cards.
- P2–P4 close every imported Animal, Sponsor, and Action-card dispatcher family;
  the generated data-gap report is zero.
- P5 completes conservation-token map bonuses and Release into the Wild.

P8 subsequently passed the require-no-blocking-gaps and full-match gates and
registered this action-domain layer as the default base-game Map 0 release.

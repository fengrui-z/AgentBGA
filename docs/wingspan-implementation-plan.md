# Wingspan / 展翅翱翔

分支：`codex/add-wingspan`（从当前 `codex/add-harmonies` 创建）。

## 规则基线

基础版英文版多人规则：2–5 人，170 张鸟牌，26 张奖励卡，8 枚双面目标板块，
绿色竞争计分 / 蓝色非竞争计分，四轮每人 8/7/6/5 次行动。
独立编写规则引擎，使用结构化机械数据与原创 Web 界面。
不包含 Swift-Start 教学牌、扩展、Automa 独立单人规则或出版商美术。

来源：
- [官方规则及勘误](https://stonemaiergames.com/games/wingspan/rules/)
- [官方 Rulepop 参考](https://wingspan.rulepop.com/)，只采用 core 部分。
- [Wingsearch](https://github.com/navarog/wingsearch)，固定提交
  `43e5036de9e68fa9c4fabaf4c760412a887adf05`；基础牌字段来自
  `src/assets/data/master.json`（TawnyFrogmouth 转录数据，GPL-3.0）。
  筛选 `Set == core` 且不含 `Swift Start`；同人奖励卡不纳入。
  只转换机械数值、名称和匹配标签；能力改为独立编写的结构化操作，不打包卡面/风味文字。
  数据许可见 `src/agentbga/wingspan/CATALOG_LICENSE.txt`。
- 奖励卡采用基础版数值；Backyard Birder 的高档为 7+，Photographer 为 4–5/6+，
  Rodentologist 计任何含鼠类图标的鸟，Spotted Sandpiper 为 5 分。

## 实现与验收

- [x] 初始留牌/弃食物/奖励卡选择、四轮、三栖息地行动、支付与终局。
- [x] 所有基础版能力，包括白色额外打鸟、褐色重复、迁徙、捕食、粉色反应。
- [x] 保密观察、动作脱敏、非法动作原子性、库存守恒、确定性回放。
- [x] CLI / Store / Harness / Web 接入与中英双语界面。
- [x] 规则场景、全牌能力、2–5 人完局、持久化回放、前端构建与浏览器验收。

## 关键设计

连续能力使用可序列化队列；玩家的完整行动与协议决策步分开计数。
食物、鸟蛋、奖励卡和其他玩家奖励均由对应玩家逐步选择。
公开观察不包含随机数状态、牌堆顺序、对手手牌、奖励卡、弃牌或隐藏压卡身份。

## 验证记录（2026-09-15）

- 最终 Python 全量：544 通过、17 跳过、359 个子场景通过；Wingspan 专属 25 项测试及 170 张逐牌子场景通过。
- wheel 构建、安装到独立目录并从项目外运行双人完整对局通过；牌库、来源元数据和 GPL 许可证均随包提供。

- 170 张鸟牌逐张执行能力路径，覆盖 67 种参数组合、25 类操作；每步校验牌库和奖励卡守恒。
- 场景覆盖起始资源取舍、2:1 食物替代、鸟蛋支付与容量、万能巢、严格捕食翼展阈值、
  空鸟食器与同面重掷、迁徙、能力重复、粉色反应、回合末弃牌、额外打鸟、轮末并列和奖励卡边界。
- 2–5 人、两种目标板完成对局；逐决策 JSON 往返执行，状态哈希和事件相同，每人恰好 26 次完整行动。
- Store/Runner 完局、SQLite 重新打开与种子/动作重放通过；CLI 五人配置与真实双人随机运行通过。
- Web 两名人类通过 API 完整走完对局并恢复终局，覆盖打鸟和能力选择。
- 浏览器真实操作覆盖留牌、弃食物、选奖励卡、打鸟支付、产蛋、抽牌、激活能力、回合末弃牌和刷新恢复。
  桌面和 390px 窄屏验证；窄屏页面宽度与可视宽度同为 390px。
- Web TypeScript、ESLint、构建通过；5 项选择器测试和 14 项真实组件/静态导出测试通过。

## 范围与实现边界

- 状态为 `playable_beta`：全基础版多人机械范围已接通，社区转录数据与独立实现未经出版商认证。
- 2–5 人；Automa 单人规则作为独立范围，当前不提供 1 人配置。
- 采用基础版英文奖励卡关键词与数值，不引入扩展追加的身体部位关键词或重印奖励卡数值。
- 不含出版商图片、Swift-Start 教学牌、扩展或真实付费模型对战验证。
- 玩家完整行动计数为 `completed_turns`；`turn_count` 是逐项选择的协议决策计数。
- 规则与中文描述为独立编写的速查说明；名称类奖励卡始终按英文鸟名计算。
